Trois marqueurs enregistrés
  - finetune_trigger : instant de déclenchement (wall-clock au moment du lancement du fit).
  - hotswap : instant de chaque hot-swap réussi (existait déjà pour les plots).
  - compute_time_s : temps de calcul = hot-swap − déclenchement (la soustraction entre les deux repères), calculé dans le callback _on_hotswap.

  Dans le CSV ({session}.csv)

  save_history_to_csv (dans RL-real/utils.py) reçoit maintenant events et ajoute deux colonnes :
  - event : 'finetune_trigger' ou 'hotswap' sur la ligne dont le time est le plus proche de l'évènement,
  - compute_time_s : le temps de calcul, posé sur la ligne du hot-swap.
  
  Les instants sont écrits dans le même repère temporel que la colonne time (relatif au début du vol RL, comme les marqueurs des plots), donc pour retracer tu filtres simplement
  df[df.event != ''].
